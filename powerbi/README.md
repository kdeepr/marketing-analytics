# Power BI Dashboard - Setup Guide

## A note on how this was built

Power BI Desktop is a Windows GUI application with no CLI or headless build
mode, and it isn't available on the macOS/CLI environment this project was
built in - so a `.pbix` file could not be authored or executed here. Rather
than fake one, this folder gives you everything needed to build the real
dashboard yourself in Power BI Desktop in about 10-15 minutes: a
dashboard-ready **star schema** exported from the modeled data, and the
exact **DAX measures, relationships, and visuals** to add. If you'd rather
skip Power BI Desktop entirely, `powerbi/data/*.csv` also loads directly
into Excel PivotTables or Tableau using the same model described below.

## Data model (star schema)

All files are in `powerbi/data/`, generated by `src/export_powerbi.py`
(run `python -m src.export_powerbi` to regenerate after any pipeline change).

| File | Role | Grain |
|---|---|---|
| `fact_campaign_contacts.csv` | Fact table | 1 row per campaign contact (41,176 rows) |
| `dim_date.csv` | Date dimension | 1 row per distinct contact date |
| `segment_summary.csv` | Pre-aggregated summary | 1 row per job x age_group x education x month, for fast-loading top-level visuals |

**Relationship to create in Power BI:** `fact_campaign_contacts[date_key]`
(many) -> `dim_date[date_key]` (one).

**Important - synthetic dates:** the source dataset only records the
*month* and *day-of-week* of each contact (e.g. "may", "mon"), not the day
or year. `dim_date` and `fact_campaign_contacts[date_key]` reconstruct a
plausible daily sequence consistent with the documented campaign window
(May 2008 - Nov 2010) and the dataset's chronological row order, purely so
the dashboard can demonstrate real time-intelligence DAX. Treat the date
axis as illustrative rather than the literal calendar date of each
historical call - `month`, `quarter`, and `day_of_week` (also included as
plain text columns on the fact table) are the trustworthy time fields.

### Key fields on `fact_campaign_contacts`

- **Dimensions:** `job`, `marital`, `education`, `default`, `housing`,
  `loan`, `contact` (channel), `month`, `quarter`, `day_of_week`,
  `age_group`, `campaign_bucket`, `pdays_bucket`, `poutcome`
- **Metrics:** `subscribed` (0/1 actual outcome), `predicted_propensity`
  (0-1 score from the trained "realistic" model, see
  `notebooks/03_modeling.ipynb`), `predicted_label`, `duration`,
  `campaign`, `previous`, plus the five macro-economic indicators
  (`emp_var_rate`, `cons_price_idx`, `cons_conf_idx`, `euribor3m`,
  `nr_employed`)

## Steps to build the dashboard

1. Open **Power BI Desktop** -> **Get Data** -> **Text/CSV** -> load all
   three files from `powerbi/data/`.
2. In **Model view**, drag `date_key` from `fact_campaign_contacts` onto
   `date_key` in `dim_date` to create the relationship (cardinality
   many-to-one, single direction).
3. Mark `dim_date[date]` as a **Date table** (Table tools -> Mark as date
   table) to enable time-intelligence DAX.
4. Create the measures below (Home -> New measure).
5. Build the pages/visuals listed further down.

## DAX measures

```DAX
Total Contacts = COUNTROWS(fact_campaign_contacts)

Total Subscriptions = SUM(fact_campaign_contacts[subscribed])

Conversion Rate =
DIVIDE([Total Subscriptions], [Total Contacts])

Avg Predicted Propensity =
AVERAGE(fact_campaign_contacts[predicted_propensity])

Model Precision (Predicted Positive) =
VAR TP = CALCULATE([Total Subscriptions], fact_campaign_contacts[predicted_label] = 1)
VAR PredictedPositive = CALCULATE([Total Contacts], fact_campaign_contacts[predicted_label] = 1)
RETURN DIVIDE(TP, PredictedPositive)

Conversion Rate LY (time intelligence demo) =
CALCULATE([Conversion Rate], SAMEPERIODLASTYEAR(dim_date[date]))

High Propensity Untapped Leads =
CALCULATE(
    [Total Contacts],
    fact_campaign_contacts[predicted_propensity] >= 0.5,
    fact_campaign_contacts[subscribed] = 0
)

Contacts per Subscription =
DIVIDE([Total Contacts], [Total Subscriptions])
```

## Suggested pages & visuals

**1. Campaign Overview**
- KPI cards: `Total Contacts`, `Total Subscriptions`, `Conversion Rate`,
  `Contacts per Subscription`
- Line chart: `Conversion Rate` by `dim_date[month_name]` (sorted by
  `month_num`) - shows the strong seasonality found in the EDA
  (`notebooks/01_eda.ipynb`)
- Bar chart: `Conversion Rate` by `job`, sorted descending
- Slicers: `quarter`, `contact` (channel), `poutcome`

**2. Segment Deep-Dive** (built from `segment_summary.csv` for speed)
- Matrix: rows = `job`, columns = `age_group`, values =
  `AVERAGE(segment_summary[conversion_rate])`
- Scatter: `avg_predicted_propensity` vs `conversion_rate` by segment,
  size = `contacts` - flags segments the model rates highly that the bank
  is under-targeting
- Table: top 10 segments by `conversion_rate` (min `contacts` >= 100)

**3. Predictive Targeting** (the model-driven page)
- Histogram: distribution of `predicted_propensity`
- Card: `High Propensity Untapped Leads`
- Table: contacts with `subscribed = 0` and `predicted_propensity >= 0.6`,
  sorted descending - a ready-to-export "next best targets" call list
- Gauge/KPI: `Model Precision (Predicted Positive)` vs. the baseline
  `Conversion Rate`, to show lift over calling at random

**4. Economic Context**
- Line chart: `euribor3m`, `emp_var_rate`, `cons_conf_idx` over
  `dim_date[date]` (dual axis) with `Conversion Rate` overlaid - visualizes
  the R ANOVA/logistic-regression finding that macro conditions move
  conversion (`r/statistical_analysis.R`)

## Design notes

- Use a single accent color for "positive/subscribed" states (e.g. the
  green `#2f6f4f` used throughout the Python/R charts) and a neutral grey
  for "not subscribed", for visual consistency with the notebooks and
  `reports/figures/`.
- Default every page's contact-volume visuals to sort by volume; default
  conversion-rate visuals to sort by rate, not alphabetically, so the
  segments that matter surface first.
